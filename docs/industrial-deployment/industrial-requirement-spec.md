# 钢板视觉质量检测系统工业需求规格

> 文档性质：模拟客户需求，用于工业交付演练；其中业务量、成本和目标值均为 simulation assumption，不代表真实客户承诺。

## 1. 客户与问题

客户是一家连续生产钢板的制造企业。当前依赖人工抽检和终检，存在检测节拍不稳定、疲劳导致漏检、班组间判定一致性不足，以及质量记录难以追溯的问题。项目目标是在不改变已冻结 D3 模型、权重、whitening、bank、feature extractor 和 threshold 的前提下，交付 AI 辅助质量检测系统。

## 2. 业务目标

- 对进入工位的钢板图像执行自动检测，将 PASS、REJECT、HOLD 结果送入 PLC/MES/人工复核闭环。
- 降低人工逐件检查负荷，同时保留 HOLD 和争议样本的人工最终裁决权。
- 每次判定关联产品、批次、相机、模型版本、artifact hash、时间戳和后续处置。
- 任何相机、推理、artifact 或控制链异常均 fail closed，不得将未知状态判为 PASS。

## 3. 技术指标

| 指标 | 验收目标 | 说明 |
|---|---:|---|
| 冻结模型 | D3 DINOv2 ViT-B/14 + ZCA | 不允许现场训练或调参 |
| 图像 AUROC | 0.8179071714278028 | 已有冻结评估指标，不重新定义 |
| 像素 AUROC | 0.9241393857425543 | 已有冻结评估指标，不重新定义 |
| AUPRO | 0.7993981069909584 | 已有冻结评估指标，不重新定义 |
| artifact 完整性 | 100% SHA-256 匹配 | 启动、晋升和回滚均校验 |
| 追溯字段完整率 | 100% | 产品、批次、相机、模型、判定、处置 |
| 控制结果 | PASS/REJECT/HOLD 全映射 | 未知或失败状态一律 HOLD |

## 4. SLA（simulation assumption）

| 服务项 | 目标 |
|---|---:|
| 计划生产时段可用性 | ≥ 99.5% / 月 |
| 单次推理到决策 P95 | ≤ 1.5 s |
| PLC 指令确认 P95 | ≤ 300 ms |
| 关键告警触达 | ≤ 60 s |
| HOLD 人工响应 | ≤ 10 min |
| 审计记录保留 | ≥ 365 天 |
| RTO / RPO | 30 min / 5 min |

SLA 排除已批准的计划维护、上游停线和客户网络整体不可用。SLA 统计必须来自监控记录，不以人工估计代替。

## 5. 安全要求

- Camera/PLC 位于 OT 区；Dashboard、MES 连接位于受控服务区；禁止互联网直接访问 OT。
- 服务账户使用最小权限；操作员可查看和复核，工程师可执行受审批的回滚，只有发布负责人可晋升模型。
- artifact、manifest 和依赖锁使用 SHA-256 校验；不匹配时拒绝加载或晋升。
- PLC 写入采用允许列表和幂等命令；所有控制、人工复核和生命周期变更写入审计日志。
- 凭据通过运行环境注入，不写入仓库、日志或 Dashboard。

## 6. 验收标准

1. 现场验收测试覆盖 Camera → Edge Runtime → D3 inference → Decision → PLC → MES → Human Review → Monitoring。
2. 相机断连、推理异常、artifact 缺失/hash mismatch、PLC 超时均产生 HOLD，且保留原因码。
3. Drift Warning 仅告警并观察；Drift Critical 触发 HOLD；两者均不自动调 threshold 或训练。
4. `/operations` 显示当前模型版本、生命周期状态、artifact hash 和回滚状态；`/model` 显示版本历史、指标与审批状态。
5. 回滚演练验证目标版本 artifact hash 与登记值一致，并保留操作员、原因和时间戳。
6. 交付测试通过，冻结 D3 文件在实施前后的 SHA-256 完全一致。
