# 工业视觉 AI 业务价值分析

> 本文全部业务量、人员、成本、速度、漏检率和收益数字均为 **simulation assumption**，仅用于方案测算，不是生产事实、报价或收益承诺。

## 1. Baseline：人工检测

| 项目 | simulation assumption |
|---|---:|
| 检测人员 | 6 人 |
| 单人年综合成本 | ¥120,000 |
| 年人工成本 | ¥720,000 |
| 检测速度 | 18 件/分钟/工位 |
| 年检测量 | 1,200,000 件 |
| 漏检率 | 0.25% |
| 单件漏检预期损失 | ¥180 |

人工方案受疲劳、班次和经验差异影响，风险集中在漏检、返工/索赔以及质量证据不完整。

## 2. AI 方案

| 项目 | simulation assumption |
|---|---:|
| 自动处置比例 | 82% |
| 人工复核比例 | 18% |
| 可转移人工负荷 | 70% |
| 系统处理能力 | 60 件/分钟/工位 |
| AI 后漏检率 | 0.10% |
| 首期投入 | ¥1,350,000 |
| 年运行维护成本 | ¥180,000 |

“可转移人工负荷”表示人员可转岗到复核、工艺改善或其他工位，并不等同于强制裁员。系统保持 HOLD 和人工最终裁决机制。

## 3. 计算

计算口径与 `business_analysis.roi.calculate_roi` 一致：

- 人工成本节省 = 6 × ¥120,000 × 70% = **¥504,000/年**。
- 漏检减少 = (0.25% − 0.10%) × 1,200,000 = **1,800 件/年**。
- 质量损失避免 = 1,800 × ¥180 = **¥324,000/年**。
- 年净收益 = ¥504,000 + ¥324,000 − ¥180,000 = **¥648,000/年**。
- Detection improvement：漏检率绝对下降 **0.15 个百分点**，相对下降 **60%**。
- 首年简单 ROI = ¥648,000 ÷ ¥1,350,000 = **48.0%**。
- Payback period = ¥1,350,000 ÷ ¥648,000 = **2.08 年（约 25 个月）**。
- 理论节拍提升 = 60 ÷ 18 − 1 = **233%**；实际产线收益仍受上下料和 PLC 节拍约束。

## 4. 敏感性与边界

若年净收益不为正，则 payback period 记为不可回收，不用负数表达。ROI 不计税、资金成本、折旧、停线实施成本和产能增量收入；真实立项前必须以现场四周基线、财务确认成本和受控 A/B 运行数据替换全部 simulation assumption。

业务验收应同时观察漏检、误拦截、HOLD/复核负荷、停线时间和客户投诉，不能只追求自动化比例。
