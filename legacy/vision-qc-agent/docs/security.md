# 安全设计

- API Key 只从运行时环境变量读取；示例、日志、审计和模型调用记录都不保存 Key。
- 图片同时校验扩展名、声明 MIME、字节数、Pillow 实际解码格式；存储名使用随机 UUID。
- Provider 响应必须通过 `extra="forbid"` 的 Pydantic v2 Schema。
- HTTP Provider 配置连接总超时和指数退避重试；对外只返回脱敏错误码。
- Provider 不可用时不会放行或自动停线，而是安全降级到人工复检。
- 每个上传请求和每个模拟工具动作都有独立幂等键。
- 停线建议只创建待审批动作；人工批准后才会生成执行动作。
- Docker 镜像不复制仓库根 `.env`，服务使用非 root 用户运行。
- CI 强制 `AI_MODE=mock`，不配置任何真实 Provider Key。

生产部署仍应在网关补充身份认证、基于角色的授权、恶意文件扫描、速率限制、集中式密钥管理和不可篡改审计存储。
